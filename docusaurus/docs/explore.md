# Explore Factory

Factory is an open-source reference implementation for building and running
your own infrastructure platform. It's a practical example you can learn from
and adapt to your organization.

Factory brings open-source tools together to define infrastructure as code,
review changes, and work across environments. Its local integration stack
offers a way to explore how components work together.

- [Explore the ecosystem](/ecosystem) of projects and tools used by Factory.
- [Browse the source](https://github.com/osinfra-io/factory).
- [Try Factory locally](./local-development.md).

For implementation and operations, see [Run Factory](./run.md). For
development teams using the platform, see [Use Factory](./use.md).
