# Factory

An open-source, AI-powered Infrastructure as Code factory.

## Architecture

Factory is organized into three layers:

### Foundation

Establishes the organizational foundations, identity, integrations, and governance.

### Assembly

Composes and provisions cloud infrastructure, projects, environments, and resources.

### Runtime

Provides the execution environment and workload capabilities.

**Floor** is Factory's local execution and orchestration environment. It operates across the layers and is not a fourth layer.
